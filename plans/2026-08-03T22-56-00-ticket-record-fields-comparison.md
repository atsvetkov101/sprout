# Сравнение полей объекта Заявка (TicketRecord)

## Требуемые поля

| Поле | Описание |
|------|----------|
| `id` | Идентификатор |
| `status` | Статус заявки («новая» / «назначена» / «отменена» и др.) |
| `external_id` | Идентификатор внешний |
| `service` | Категория заявки |
| `deadline` | Контрольный срок |
| `assignee_id` | Идентификатор исполнителя |
| `act_type` | Тип акта о выполненных работах |

## Текущая реализация `TicketRecord`

Файл: [`ticket-record.ts`](../Tickets/src/Tickets.Domain/entities/ticket-record.ts)

| Поле | Тип | Наличие |
|------|-----|---------|
| `id` | `string` | ✅ есть |
| `assignee_id` | `number` | ✅ есть |
| `status` | `TicketRecordStatus` | ✅ есть |
| `service` | `string` | ✅ есть |
| `deadline` | `Date` | ✅ есть |
| `act_type` | `string` | ✅ есть |
| `external_id` | — | ❌ отсутствует |

## Результат сравнения

| Требуемое поле | Статус | Комментарий |
|----------------|--------|-------------|
| `id` | ✅ совпадает | Присутствует как `id: string` |
| `status` | ✅ совпадает | Присутствует как `status: TicketRecordStatus` |
| `external_id` | ❌ отсутствует | Поле не реализовано в текущей версии |
| `service` | ✅ совпадает | Присутствует как `service: string` |
| `deadline` | ✅ совпадает | Присутствует как `deadline: Date` |
| `assignee_id` | ✅ совпадает | Присутствует как `assignee_id: number` |
| `act_type` | ✅ совпадает | Присутствует как `act_type: string` |

## Дополнительные поля в текущей реализации (не входят в требуемый список)

- `created_by` — создатель заявки
- `created_time` — время создания
- `wiki_link` — ссылка на вики
- `is_service_change_available` — доступность смены сервиса
- `events` — доменные события

## Вывод

Из 7 требуемых полей в текущей реализации `TicketRecord` присутствуют **6**. Отсутствует только поле **`external_id`** (внешний идентификатор). Остальные требуемые поля полностью совпадают по назначению и типу.

### Статусы заявки (для справки)

Из [`ticket-record-status.ts`](../Tickets/src/Tickets.Domain/vo/ticket-record-status.ts):

| Значение | Статус |
|----------|--------|
| `new` | новая |
| `assigned` | назначена |
| `in_progress` | в работе |
| `done` | выполнена |
| `canceled` | отменена |
| `closed` | закрыта |
