# Этап 1 — Стратегическое проектирование

Цель: определить ландшафт системы, выделить границы и договориться о языке.

## Задачи

1. **Субдомены** — выделить 4–5 субдоменов, классифицировать (Core / Supporting / Generic), обосновать выбор Core-субдомена.
2. **Единый язык (Ubiquitous Language)** — глоссарий из 10–15 ключевых терминов Core-субдомена с определениями и недопустимыми синонимами.
3. **Карта контекстов (Context Map)** — разбить систему на Ограниченные контексты(Bounded Contexts), нарисовать карту, указать паттерны интеграции (Customer-Supplier, ACL, Conformist, Partnership) и направления зависимостей (Upstream/Downstream), объяснить выбор для 2–3 ключевых связей.

## Артефакты

- `subdomains.md` — субдомены и их классификация.
- `ubiquitous-language.md` — глоссарий.
- `context-map.md` — список Ограниченных контекстов Bounded (Contexts) и визуальная карта контекстов (Context Map)
