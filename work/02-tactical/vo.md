# Value Objects контекста Tickets

`Coords` — неизменяемый value object, представляющий географическую точку и задаваемый парой строковых компонент `lat` (широта) и `lng` (долгота). Инвариант устанавливается в конструкторе через статический предикат `isValid(lat, lng)` и выполняется в течение всего времени жизни объекта: оба аргумента обязаны быть непустыми строками, представимыми конечными числами (`Number.parseFloat`), при этом числовое значение широты лежит в интервале [−90; 90], долготы — в [−180; 180]. Нарушение инварианта приводит к `throw new Error('Некорректные координаты: ...')`, то есть экземпляр с некорректными координатами не может быть создан. Объект раскрывает компоненты только для чтения через `getLat()` / `getLng()` и сериализуется в канонический вид `"lat,lng"` методом `toString()`. Равенство определяется по значению: `equals(other)` сравнивает обе компоненты, поэтому два разных экземпляра с идентичными координатами считаются равными. В модели объект применяется двояко: как одиночная координата точки (например, `coords?: Coords` объекта сервиса) и как элемент трека (`coords_list: Coords[]`, возвращаемый `getCoordsList()`); в обоих случаях используется одна и та же неизменяемая семантика.

`WorkHours` представляет недельное расписание работы и агрегирует набор `WorkHour` (временные диапазоны) по дням недели (`DayOfWeek` по ISO, 1 = Понедельник … 7 = Воскресенье). При создании валидирует данные (день в пределах недели, непустой список диапазонов, отсутствие пересечений) и нормализует их, сортируя диапазоны по времени начала. Потребитель оперирует им через семантические методы: `isOpenOn(day)` / `isOpenAt(day, time)` для проверки доступности, `getHoursForDay(day)` и `getDays()` для получения диапазонов и дней работы, а `equals()` сравнивает расписания по значению. Оба объекта неизменяемы и сравниваются по значению
