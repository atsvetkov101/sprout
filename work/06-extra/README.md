# Задание со звёздочкой (\*) — дополнительная инфраструктура

Для тех, кто хочет максимум практического опыта и реальной инфраструктуры.

## Задачи

1. **Infrastructure as Code (Docker Compose)** — файл `docker-compose.yml`: БД, брокер сообщений (RabbitMQ/Kafka), observability (Jaeger + Prometheus + Grafana).
2. **Реализация Outbox Worker** — фоновый процесс, читающий записи из таблицы Outbox и публикующий их в брокер; опционально — микросервис мониторинга нагрузки/выручки.

## Артефакты (план)

- `docker-compose.yml` — стек инфраструктуры.
- `outbox-worker/` — реализация фонового процесса.
- `metrics/` — мониторинг нагрузки/выручки.
